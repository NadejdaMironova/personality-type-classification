# Классификация типов личности (Introvert / Ambivert / Extrovert)

## Задача
Построить модель, которая определяет тип личности по 29 числовым признакам (шкала 0–10), и выяснить, можно ли сократить опросник без заметной потери качества.

## Данные
Синтетический датасет: 20 000 объектов, 29 признаков, 3 сбалансированных класса. Пропусков и дубликатов нет.

## Что сделано
- Разведочный анализ данных: распределения, корреляции Спирмена, средние по типам личности
- Создание 2 новых признаков, стандартизация без утечки данных
- Сравнение 4 моделей (Logistic Regression, KNN, SVC, Random Forest) с подбором гиперпараметров через GridSearchCV и 5-кратную кросс-валидацию
- Отбор признаков тремя методами: F-тест, RFE, важность признаков Random Forest
- Визуализация с помощью PCA и LDA, анализ ошибок моделей

## Результаты
- Logistic Regression, SVC и KNN: accuracy 0.9975 на тесте (10 ошибок на 4 000 объектов)
- Random Forest: accuracy 0.994
- Опросник можно сократить с 29 до 12–13 вопросов, потеря macro F1 примерно 0.3–0.6 п.п.
- Ошибки сосредоточены на границе класса Ambivert с соседними типами

## Ограничение
Данные синтетические, на реальных данных качество, скорее всего, будет ниже.
